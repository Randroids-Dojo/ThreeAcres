# Three Acres

Three farming games on one farm, to find out which kind of farming game is the most fun.

- **Sunup**: a day on the homestead. Walk your rows in a real-time day, water, pull, ship, sleep.
- **Patchwork**: the almanac puzzle. Twelve moves a day, companion planting, soil and seasonal goals.
- **Bushel & Co.**: the farm that runs itself. Farmhands, town orders and a clock you speed up.

Every rule is its own switch (view, camera, control, clock, soil, goal, weather, crew, tools), and any switch can be flipped at any moment without losing the farm. The mix panel keeps time spent per option and lab notes stamped with the mix.

```bash
npm install
npm run dev        # http://localhost:5247
npm test
npm run build
```
